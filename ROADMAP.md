# KIMI Base OS Roadmap

## Next major subsystem: Teleport System

Build a KIMI-managed teleport network after the alpha73 base-nervous-system release is stable.

Goals:
- discover and name teleport destinations
- show destination online/offline/energy readiness
- select destinations from Command Center and Pocket
- safe confirmation before teleport activation
- expose cooldown/energy/availability telemetry when the teleport mod API allows it
- never let KIMI bypass the teleport mod's own safety or permission rules

## Later ideas
- Builder/quarry start/stop controls only after read-only telemetry is proven stable
- richer AE2 crafting/job drill-down
- alert rules for power, quarry completion and offline infrastructure
