# Third-party software

KIMI Base OS integrates with the public `MikaylaFischler/cc-mek-scada` project.

The KIMI bridge does not vendor or modify cc-mek-scada source code. It downloads official upstream deployment builds from the project's published GitHub Pages manifests/builds and launches the installed upstream application unchanged.

cc-mek-scada is distributed under the MIT License. Preserve the upstream `LICENSE` file installed by cc-mek-scada with the SCADA installation.
